# 清风村 · 山河初醒

无依赖的竖屏 Canvas 2D 游戏原型。无需构建或联网。

## 在另一台电脑继续开发

先安装 [Git](https://git-scm.com/) 和 [Node.js](https://nodejs.org/)，然后在终端运行：

```bash
git clone https://github.com/xyz537/qingfeng-village-game.git
cd qingfeng-village-game
npm test
npm start
```

浏览器打开 http://127.0.0.1:4173 即可试玩本地版本。修改完成并确认测试通过后，用 GitHub Desktop 提交并推送，或运行：

```bash
git add .
git commit -m "描述本次修改"
git push
```

仓库根目录同时也是 GitHub Pages 的发布目录，推送到 `main` 后，在线试玩版会由 GitHub 自动更新。每台电脑的浏览器存档保存在本机，不会随 Git 仓库同步。

## 启动

推荐双击 `start.bat`，或在此文件夹运行 `node server.cjs`，再打开 http://127.0.0.1:4173 。关闭启动窗口即可停止服务。也可以直接双击 `index.html` 游玩；部分浏览器对本地文件存档有限制。直接打开与通过服务打开的存档分别保存在各自浏览器来源中。

## 操作

- 点击地图上的道路或空地，主角自动绕过山体、水域、房屋、树干和栅栏走到目的地；点击无法落脚或暂不可直达的位置时，会自动改往离点击处最近的可到达空地。行走时只显示目的地光标，途中可点击新位置改道，或点击「停下」。鼠标和触屏操作相同。
- 远处点击人物、建筑、田地或钓鱼码头时先走近，靠近后再点击触发。地图下方会显示附近对象的独立按钮，方便选择相邻的田地或人物。
- 人物对话使用顶部小框：NPC 位于左上，主角位于右上，配有人物头像和姓名。点击小框逐句继续，长句自动分页；Enter/空格可继续，× 或 Esc 可结束对话。
- 种田、钓鱼、读书、饮食、铁匠铺、村志和行囊也统一使用同款顶部对话框，在框内直接选择操作。
- 室内点击案台使用设施，点击门口、楼梯或后门切换场景；所有生活操作和对话选项使用点击。
- 默认一现实秒对应一游戏分钟，即现实 24 分钟为游戏一天；「时间 ×8」和「歇息一时辰」可加快等待。菜单中时间继续；页面保持打开时，切到后台再回来会补算经过的现实时间。关闭页面期间不补算。
- 每四秒及关键操作自动本地存档。清除浏览器该页面的站点数据即可重开。存档暂不含正在钓的鱼。

## 自动战斗 V0.1

从村庄南侧沿路出村，进入「村外古道」后会看见一名持柴刀的山贼。点击远处山贼时，主角会先自动走近；进入交互范围后再次点击山贼或地图下方的「与拦路山贼交涉」，选择「拔剑迎战」即可进入独立战斗场地。选择「暂且退开」不会开始战斗。

战斗完全自动进行。主角会根据山贼的攻击选择进攻、招架或闪避，山贼只会接近、挥刀，并可能在气血极低时逃跑。场地上方显示双方 HP、内力、AI 等级、当前动作和最近决策，下方显示战斗记录。战斗结束后可选择「重新挑战」或「返回古道」。战斗数据不会写入生活存档，也不会改变主角在村中的永久属性。

## 已实现

依照用户参考图重制的 3:4 像素风清风村底图和角色图集、点击目的地自动寻路、山体/水域/房屋/树干/栅栏碰撞、靠近后点击互动、八个可走动室内场景、村外古道往返、日夜染色和年月日期。通往农田的石桥位于民居与私塾之间，桥面碰撞和寻路已同步移动。人物移动使用手臂与双脚交替的四帧步行动画，头部和躯干保持稳定；顾先生、赵铁山和周伯庸的后两帧由补充图集提供。

药铺一层、药铺二楼、医馆后院、酒馆一层、酒馆二楼和私塾主教室使用参考图布局重绘的独立室内底图，并设置了与药柜、柜台、床铺、药圃和课桌对应的行走碰撞。楼梯与药铺后门可通过点击自动寻路并切换楼层/后院；卧房、客房和后院药材设有查看点。铁匠铺和村长家仍使用原型室内画面。

十二名村民按清晨、上午、中午、下午、晚上和深夜六个时段生活，并自动冒出当前活动相关的对白。苏怀仁坐诊和炮制药材，顾先生授课和写信，赵铁山开炉和修理，周伯庸处理村务和巡视，酒馆掌柜随客流忙碌；采药、串门、去酒馆等偶发活动按日期变化。村外古道现有一名独立像素角色山贼，可通过对话进入 1V1 自动战斗，观察不同 AI 层级的行为差异。

四种作物播种/时间成熟/收获/出售；两种饵料、抛竿等待和收杆；酒馆坐下、饮食和售卖鲜货；付费上课、学识阅读门槛、代读残篇；铁匠购买、材料打造、修理和跨日领取；自动推进的步道整修村务、可选捐款和动态村志；行囊与铜钱。

## 范围与地图说明

已根据用户提供的概念地图定位药铺、村长家、铁匠铺、私塾、酒馆、村心、河流与石桥、钓鱼码头、东岸农田、村口和官道。原参考图里还包括后山、山洞和渡口；本版保留它们的视觉背景，暂未加入深入内容。人物已经具备正面四帧步行循环，侧面和背面动作帧可在后续美术制作中补充。

铁匠铺、村长家和村外古道环境仍是占位绘制。战斗目前只有古道山贼 1V1 原型，未制作武学演练、关系成长、NPC 老化、复杂耐久、后山、山洞、渡口及村外完整内容。残页目前只记录理解状态。种植用游戏小时加速呈现，非写实农时。没有主线、接任务页面或任务标记。

## 扩展结构

- `assets/village-map.png`、`assets/villagers-atlas.png`：以参考图编辑和生成的室外地图与角色美术。
- `assets/villagers-walk.png`、`assets/villagers-walk-extra.png`：九名角色的手脚交替步行帧及三名中间角色的补充帧。
- `assets/home-interior.png`、`assets/home-second-floor.png`、`assets/home-yard.png`：药铺一层、二楼和后院。
- `assets/tavern-interior.png`、`assets/tavern-second-floor.png`：酒馆一层和二楼客房。
- `assets/school-interior.png`：私塾主教室。
- `data.js`：地图位置、建筑、营业时间、作物和 NPC 文本。
- `engine.js`：存档状态、时间、交易、农作物、订单、村务纯逻辑。
- `navigation.js`：共用碰撞规则的网格寻路，防止穿墙和斜向穿过障碍角落。
- `combat.js`：自动战斗角色模板、三级 AI、行动计时、伤害结算与战斗日志。
- `game.js`：输入、绘制、场景、日程及交互界面。
- `style.css`：适配竖屏的界面。
- `server.cjs`：仅本机静态服务；`test.cjs`：自动检查，运行 `node test.cjs`。

下一步：在真实浏览器中试玩栅栏边缘、室内家具碰撞和触屏操作；制作角色逐方向动作帧，再让村民沿道路实际走入和走出建筑，最后扩展人物关系和事件。
